# Al-Manadeeb Creative Services: Social Posts

Public media host for the daily social media posts of **Al-Manadeeb Creative Services** (Doha, Qatar).

- `schedule.json`: posting date → content folder (Asia/Qatar, 08:27)
- `posts/DayNN_*`: one folder per day: square post (JPG), story (JPG), 10s vertical video (MP4), caption and `post.json`
- `publish_day.py`: publisher used by the scheduled daily task
